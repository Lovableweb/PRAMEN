# 3. PRAVIDLA PRO BUDOUCÍHO HISTORIKA

Historik nesmí pouze odpovědět „ano/ne“.
U každé odpovědi musí být pokud možno uvedeno:

- odpověď,
- konkrétní pramen,
- autor,
- název díla,
- rok,
- strana / folio / kapitola, pokud je dostupná,
- odkaz na digitalizát, katalog nebo archiv, pokud existuje,
- důkazní úroveň,
- případná nejistota.

Používej označení:

🟢 DOLOŽENO
🟡 VYŽADUJE DALŠÍ OVĚŘENÍ
🔴 NEDOLOŽENO / NELZE POUŽÍT JAKO HISTORICKÝ FAKT
⚠️ SPORNÉ / VYŽADUJE HISTORICKÉ POSOUZENÍ

DŮLEŽITÉ:
Historik může přinést nový pramen nebo nový výklad.
Pokud se objeví rozpor s dosavadním CORE, nesmí být automaticky přepsán CORE.
Rozpor musí být zaznamenán a předán Řídícímu mozku k posouzení.

# 4. PRAVIDLO PRO POZDĚJŠÍ ODPOVĚDI HISTORIKA

Až budou dodány odpovědi historika, jednotlivé odpovědi se mají přiřazovat ke konkrétním ID HIST-xxx.

Odpověď historika se nejprve eviduje zde jako pracovní výsledek.

Teprve po ověření Řídícím mozkem může být potvrzený výsledek převeden do:

00_CORE

a případně do dalších historických databází projektu.

# 5. POČET OTÁZEK

Počet otázek není omezen.

Pokud z dosavadního výzkumu vyplývá dalších 10, 20, 50 nebo více samostatných otázek, zachyť je všechny.

NEZKRACUJ seznam pouze kvůli pohodlí.

# 6. CO NEDĚLAT

- nevymýšlet historické odpovědi,
- nedoplňovat chybějící prameny,
- nepřepisovat historické závěry,
- neoznačovat legendu jako fakt,
- neslučovat sekundární a primární pramen,
- nepovažovat existenci digitalizátu za důkaz obsahu,
- nepovažovat pozdější odbornou interpretaci za přímý důkaz primárního pramene,
- nevytvářet nové historické skutečnosti.
